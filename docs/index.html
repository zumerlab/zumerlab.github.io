# Zumerlab

> An independent software lab building small, sharp, open-source
> web primitives. Framework-agnostic, **zero dependencies**,
> MIT-licensed, developed in the open — readable by humans **and** agents.


## Libraries

- [Orbit](https://zumerlab.com/orbit-docs/)
  CSS framework for radial UIs — gauges, donuts, knobs, pie menus,
  dashboards. **CSS only, no layout JavaScript.**

- [Zumly](https://zumerlab.com/zumly/)
  Hierarchical zoom navigation — move in **Z** through views laid
  out on the XY plane. Pluggable drivers, hash router, prefetch cache.

- [snapDOM](https://zumerlab.com/snapdom/)
  Fast, accurate DOM-to-image capture. Any element to SVG, PNG, JPG,
  WebP, canvas or Blob. **Zero dependencies.**


## Tooling & agents

> built on snapDOM

- [snapeye](https://github.com/zumerlab/snapeye)
  Eyes for AI coding agents — snapDOM in the browser, a two-endpoint
  server handler, a PNG on disk. The agent sees the result and iterates.

- [snapdiff](https://github.com/zumerlab/snapdiff)
  Client-side visual regression testing — capture in the browser, diff
  against baselines, catch changes without a headless cluster.

- [zumerBox](https://github.com/zumerlab/zumerbox)
  A dev toolkit shipped as runnable binaries — versioning, changelog,
  lint, format, build, doc extraction, test.
