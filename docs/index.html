#Zumerlab

>An independent software lab building open-source tools for the web. MIT-licensed, with source and documentation on GitHub.

##Libraries

  • -

    [Orbit](https://zumerlab.com/orbit-docs/)

    Radial interfaces in CSS: gauges, knobs, pie menus, and dashboards. No layout JavaScript.

  • -

    [Zumly](https://zumerlab.com/zumly/)

    Zoom through nested views instead of switching screens. Pluggable transitions, a hash router, and prefetching.

  • -

    [snapDOM](https://snapdom.dev/)

    Capture DOM elements as SVG, PNG, JPG, WebP, canvas, or Blob. Preserves styles and fonts. Zero dependencies.

##Tooling & agents

  • -

    [Snapeye](https://github.com/zumerlab/snapeye)

    Capture, compare, and record a running web app for coding agents. Images, visual diffs, and recordings saved to disk.

  • -

    [Snapdiff](https://github.com/zumerlab/snapdiff)

    Visual regression testing in the browser. Capture components, compare them with baselines, and review what changed.

  • -

    [SnapSurf](https://github.com/zumerlab/snapsurf)

    Web navigation and verification for AI agents, with semantic diffs and assertions after each action.

Snapeye and Snapdiff are built on SnapDOM.
